# 🦩 FlamingoAutomation

**FlamingoAutomation** is a robust automation testing framework built using **Selenium WebDriver**, **TestNG**, and **Java**. Designed for scalability and maintainability, it facilitates efficient web application testing with structured reporting and test management.

## 📁 Project Structure

FlamingoAutomation/ ├── src/ # Source code for test cases and utilities ├── extent-report/ # Generated ExtentReports for test execution ├── test-output/ # TestNG default output reports ├── .settings/ # IDE-specific settings ├── pom.xml # Maven project configuration ├── testng.xml # TestNG suite configuration ├── .classpath # Eclipse classpath settings ├── .project # Eclipse project settings

## 🚀 Features

- **Selenium WebDriver Integration**: Automate browser actions for web application testing.
- **TestNG Framework**: Manage test execution with annotations, grouping, and parallel execution.
- **ExtentReports**: Generate comprehensive and visually appealing test reports.
- **Maven Build Management**: Handle project dependencies and build lifecycle.
- **Modular Design**: Promote code reusability and easier maintenance.
